# Sprint History

GitHub Project/Issues theo dõi công việc đang diễn ra. Mỗi file trong thư mục này ghi kế hoạch ban đầu và kết quả thực tế khi Sprint kết thúc. Với Sprint đang chạy, file được cập nhật dần; khi kết thúc, hoàn thiện phần evidence và retrospective.

Quy ước tên file: `sprint-01.md`, `sprint-02.md`, ...

## Lịch sử

| Sprint | Trạng thái | Trọng tâm |
| --- | --- | --- |
| [Sprint 1](sprint-01.md) | Đã đóng | CVRP Baseline CLI |
| [Sprint 2](sprint-02.md) | Đã đóng | Hạ tầng thực nghiệm cho Clarke–Wright với điểm học được |
| Sprint 3 | Đang lập kế hoạch | Sinh instance, gán nhãn, học điểm (W2, W4, SubLists) |

## Template cho Sprint tiếp theo

```md
# Sprint N — <tên ngắn>

## Status

## Goal

## Scope

## Planned issues

## Completed

## Not completed / carried over

## Evidence

## Retrospective

### What went well

### What was blocked or difficult
```
