# Sprint History

GitHub Project/Issues theo dõi công việc đang diễn ra. Mỗi file trong thư mục này ghi kế hoạch ban đầu và kết quả thực tế khi Sprint kết thúc. Với Sprint đang chạy, file được cập nhật dần; khi kết thúc, hoàn thiện phần evidence và retrospective.

Quy ước tên file: `sprint-01.md`, `sprint-02.md`, ...

```md

## Retrospective
```
