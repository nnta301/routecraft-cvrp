# Frontend

Frontend dự kiến dùng React + TypeScript để nhập/chọn instance, chọn cấu hình, hiển thị tuyến trên tọa độ và đối chiếu tổng khoảng cách, số tuyến, tải và trạng thái khả thi. Đây là lớp hỗ trợ sử dụng và minh họa, không phải trọng tâm đánh giá thuật toán.

Trạng thái: **chưa triển khai**. Chưa có ứng dụng, dependency hay giao diện chạy được.
